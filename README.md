# UniPart

**Towards Zero-shot Language-Grounded 3D Part Segmentation for Embodied Interaction**  
ECCV 2026

Project page: https://xinqiangyu.github.io/UniPart/

UniPart is a feed-forward cross-modal 3D Transformer that maps a free-form language phrase to a functional part mask on a point cloud. We also release the construction recipe for **LangPart-1M** (160K+ Objaverse assets, 8M text–part pairs) and the manually verified **LangPart-4K / LangPart-1K** splits.
